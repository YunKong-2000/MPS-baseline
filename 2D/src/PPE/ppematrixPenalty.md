# 问题背景
输入：压力泊松方程离散系统 $A·p = b$，自由面粒子索引列表 $F$
目标：求解满足自由面条件 $p_i = 0 (i \in F)$ 的压力场

转化为无约束优化问题：
最小化 $J(p) = ‖A·p - b‖² + μ·‖C·p‖²$
其中 $C$ 是自由面约束矩阵

# 构造罚函数
1. 惩罚项构造：
   $P(p) = μ·\sum_{i \in F} p_i²$
   
2. 总目标函数：
$$
\begin{align*}
J(p) = ‖A·p - b‖² + P(p) = (A·p - b)ᵀ(A·p - b) + μ·pᵀCᵀC·p
\end{align*}
$$

# 构建正规方程
对$J(p)$求导并令为零：
$∇J(p) = 2Aᵀ(A·p - b) + 2μCᵀC·p = 0$

整理得：
$(AᵀA + μCᵀC)·p = Aᵀb$

# 离散化实现
设粒子总数 $n$，自由面粒子数 $m$
构造对角惩罚矩阵 
$D \in ℝ^{n×n}：$

$$D_{ii}  =  
\begin{cases}
  \mu, & i \in F \\
  0, & else
\end{cases}
$$

系统矩阵：$K = AᵀA + D$   
右端项：$f = Aᵀb$  
求解：$K·p = f$  

其中
$C = [e_{1}^T, e_{2}^T, ..., e_{m}^T]ᵀ \in  ℝ^{m×n}$  
$e_i$ 是第 $i$ 个自由面粒子的单位向量  
$CᵀC = diag\{δ_{1}, δ_{2}, ..., δ_{n}\}$  
其中 
$$
δ_j = 
\begin{cases}
1, & j \in F \\
0, & else
\end{cases}
$$
